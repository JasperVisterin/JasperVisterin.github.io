Graphs allow computers to reason about relationships. They capture the notion of who trades with whom, which papers cite each other, which node is the central node in a network or how information flows through a social network. The idea of PageRank is built on top of Graph Theory. A GNN is a neural network that can perform all the functions of a regular neural network, but on graphs. A celebrated application of a GNN is Deepmind’s AlphaFold which predicts protein 3D structure from its amino acid sequence, the elementary protein building blocks.

What if we can use them to detect fraud? Can we use the limited information we have about a graph network to predict which entities in the graph are the bad apples?

This is exactly the crux in the work of Matthias Aerts and Romain Bérard. Before this method, the main issue with state-of-the-art methods was their scalability. This work provides a solution for that. For the new SAI Belgium magazine, I wrote about this study discussing how Data Science can teach us something about graphs having only partial information.
